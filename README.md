# Number Bonds Jigsaw

A Streamlit activity for primary students to practise number bonds within 10.

A target number is shown at the top, and the digits 0–9 appear below as
jigsaw pieces in a shuffled order. Students click two pieces that add up to
the target number; correct pairs lock in place (✅) and incorrect pairs get
instant feedback.

## Features

- Choose the target number for the bonds (1–10) from the sidebar.
- Optional timer: a stopwatch (count up) or a countdown with a set time limit.
- Pieces are reshuffled each time you start a new game.
- Progress bar and a running list of pairs found.

## Run it

```bash
pip install -r requirements.txt
streamlit run app.py
```
